Vreau să construim o aplicație cross-platform numită "BreakOps"

Scopul aplicației:
O aplicație de productivitate și lifestyle pentru IT-iști / developeri care lucrează mult la birou. App-ul îi ajută să ia micro-pauze inteligente pentru ochi, gât, spate, încheieturi și reset mental, în funcție de tipul zilei de lucru, mood, nivel de energie și preferințe personale.

Aplicația trebuie să ruleze atat pe web, cat si pe mobile.

Stack dorit:
- Expo + React Native + TypeScript
- Expo Router pentru navigație
- Supabase pentru:
  - autentificare
  - database
  - user profiles
  - sync între web și mobile
- Supabase Auth cu:
  - email + password
  - Google login
  - Apple login pentru iOS
- Face ID / Touch ID cu expo-local-authentication, dar doar ca unlock local al aplicației după ce userul este deja autentificat
- AsyncStorage pentru session persistence în React Native
- Expo Notifications pentru notificări locale/push
- NativeWind/Tailwind sau alt sistem modern de styling compatibil Expo
- Chart library compatibilă cu React Native + Web pentru dashboard, de exemplu victory-native, react-native-svg-charts, echivalent compatibil sau o soluție custom cu SVG
- App trebuie să funcționeze pe:
  - iOS
  - Web
  - Android-ready, chiar dacă Android nu este prioritar în prima versiune

Important:
Nu vreau date salvate doar local. Vreau să construim de la început cu Supabase DB și autentificare.
Putem folosi local state/cache doar pentru UX, dar sursa principală de adevăr trebuie să fie Supabase.
Codul trebuie să fie production-ready, clean, modular, scalabil și ușor de extins.

Concept produs:
Aplicația trebuie să creeze un plan zilnic de recuperare pentru developer, cu micro-pauze programate în timpul zilei de lucru.

Exemple de break-uri:
- Eye Reset — 60 sec
- Neck Stretch — 2 min
- Wrist Mobility — 90 sec
- Posture Reset — 45 sec
- Breathing Reset — 2 min
- Walk Break — 5 min
- Shutdown Ritual — 3 min
- After Meeting Reset — 2 min
- Debugging Frustration Reset — 90 sec
- Deep Work Recovery — 3 min

- Coding Intens

Focus areas:

Mood / status:
Userul trebuie să poată seta mood/status pentru:
1. întreaga zi
2. un interval de ore

Exemple mood/status:
- Deep Work
- Don’t disturb
- Low energy

Dacă userul setează “Deep Work / Don’t disturb” pentru un interval, aplicația trebuie:
- să reducă notificările
- să permită doar pauze discrete/non-intrusive
- să reprogrameze pauzele neesențiale după interval
- să afișeze statusul pe dashboard

Funcționalitate principală:
1. User se autentifică
2. Dacă e prima dată, face onboarding
3. Se generează planul zilei în funcție de:
   - work_start_time
   - work_end_time
   - break_intensity
   - focus_areas
   - day_mode
   - mood/status intervals
4. User primește notificări pentru break-uri
5. User poate start/done/skip/snooze
6. Dashboard-ul se actualizează
7. Se calculează daily recovery score
8. Se afișează istoric ultimele 7 zile
9. Se afișează status săptămânal
10. Userul poate seta light/dark/system mode

Reguli pentru generarea planului:
- Light intensity: 3 pauze / zi
- Normal intensity: 5 pauze / zi
- Aggressive intensity: 7 pauze / zi
- Pauzele trebuie distribuite între start și end work time
- Să nu programeze pauze foarte aproape una de alta
- Să includă focus areas alese de user
- Dacă day_mode = Deep Work, să includă eye reset, posture reset, deep work recovery
- Dacă day_mode = Meeting Heavy, să includă breathing reset, walk break, after meeting reset
- Dacă day_mode = Low Energy, să includă breathing reset, walk break, shutdown ritual
- Dacă mood/status = Don’t Disturb pe un interval, pauzele din interval devin silent sau sunt mutate după interval
- Dacă userul skipuiește multe pauze, aplicația poate recomanda reducerea intensității

Formula simplă pentru Daily Recovery Score:
- Score pornește de la 0
- completed breaks contribuie pozitiv
- skipped/missed breaks reduc scorul
- dacă userul face cel puțin un break pentru fiecare focus area principal, bonus
- dacă userul completează shutdown ritual, bonus mic
- scor final între 0 și 100

Exemplu:
score = round((completed_breaks / total_scheduled_breaks) * 80 + bonus)
bonus maxim 20
